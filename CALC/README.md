# // RETRO_CALC_SUITE // v1.0.0

> `SYSTEM_STATUS: ONLINE`  
> `THEME: RETRO_CYBER_TERMINAL (Dark/Light Support)`

A multi-functional, retro-themed calculator and utility suite built with Python, HTML, CSS, and JavaScript. Featuring standard arithmetic, advanced unit conversions, and a dedicated tabletop RPG dice roller.

---

### 🚀 Features
- 📟 **Retro CRT Aesthetic:** Monospace typography, glowing phosphor accents, and toggleable scanline effects.
- 🌓 **Theme Engine:** Instant switching between Dark Terminal and Light Amber modes.
- 🔄 **Multi-Tool Suite:** Standard calculator, unit converter (length, weight, temperature), and a D&D dice roller (d4, d6, d8, d10, d12, d20, d100).
- 🐍 **Python Backend:** Powered by a lightweight Flask server.

---

### ⚙️ Quick Start

1. **Prerequisites:** Make sure Python is installed on your system.
2. **Install Dependencies:**
   ```bash
   pip install flask
   ```
3. **Run the Application:**
   ```bash
   python app.py
   ```
4. **Access:** Open your browser and navigate to `http://127.0.0.1:5000`.
