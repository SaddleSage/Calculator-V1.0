Pastel Glass Calculator
An aesthetic, feature-rich modern calculator web application built with HTML, Tailwind CSS, and JavaScript. Featuring a gorgeous glassmorphism UI, smooth micro-interactions, dark/light mode toggle, calculation history, keyboard support, and both standard and scientific calculation modes.

🎨 Preview & Features
Glassmorphism Design: Modern translucent panels, soft pastel gradients, and blurred backdrop effects.

Dual Modes: Easily toggle between Standard mode (basic arithmetic) and Scientific mode (trigonometry, powers, square roots, and logarithms).

Calculation History: Keep track of your previous expressions and results in a clean sidebar log, with options to clear or reuse past answers.

Dark & Light Mode: Seamlessly switch between light and dark themes with a single click.

Full Keyboard Support: Type naturally using your keyboard (0-9, operators, Enter to calculate, Backspace to delete, and Esc to clear).

Copy to Clipboard: Copy calculation results instantly with visual feedback.

Standalone & Lightweight: Built with vanilla web tech and Tailwind via CDN—no complex build tools or bundlers required.

🚀 Quick Start / Local Installation
To run this project locally on your machine, follow these simple steps:

Clone the repository:

Bash
git clone https://github.com/Sadlesage/aesthetic-calculator.git
Navigate into the project directory:

Bash
cd aesthetic-calculator
Open index.html:
Simply double-click index.html or open it in your favorite web browser (or use Live Server in VS Code).
